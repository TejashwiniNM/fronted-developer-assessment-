## Tech Stack
- HTML5
- CSS3

**Zero external libraries, frameworks, or UI kits.**

## Task 1: Exclusive Privileges

Pixel-perfect replica of ICICI "Exclusive Privileges" section.

- 4-card 3D carousel with perspective transforms
- Auto-play, touch/swipe, keyboard navigation
- Pure CSS logos (BookMyShow, ixigo)
- Responsive breakpoints

**Reference:** https://campaigns.icicibank.com/credit-card/noFee/index.html

## Task 3: Lead Capture Form

Form overlay on embedded YouTube video.

**Video Used:** https://www.youtube.com/watch?v=RJTCAL1DRro

- Triggers after 6 seconds of playback
- Progress ring countdown
